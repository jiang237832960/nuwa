# 女娲/Nuwa 阶段1需求文档

## 1. 阶段目标

**核心目标**: 建立最小执行闭环

用户输入自然语言 → 任务理解 → 感知界面 → 执行动作 → 成功完成一个简单中国高频应用任务

## 2. 功能范围

### 2.1 Android App 骨架
- 主界面：用户输入框 + 状态显示
- 任务执行界面：执行进度 + 反馈
- 设置界面：服务状态/模型管理

### 2.2 模型导入与运行
- GGUF 模型文件选择器
- 模型加载状态显示
- 基础文本生成接口

### 2.3 UI 树感知
- 实时界面捕获
- 节点树解析
- 关键元素识别

### 2.4 基础动作执行
- 点击操作
- 文本输入
- 滑动操作
- 应用切换

### 2.5 任务规划基础版
- 意图识别（中文）
- 步骤拆解
- 简单任务执行

### 2.6 世界状态基础结构
- 当前应用状态
- 设备资源状态
- 任务上下文

### 2.7 审计日志基础版
- 任务执行记录
- 动作历史
- 错误日志

### 2.8 中国应用优先矩阵第一版
- 微信
- 高德地图
- WPS
- 支付宝

## 3. 交付标准

**能稳定完成 3 ~ 5 个典型中国场景任务**：

| 任务 | 描述 | 成功率目标 |
|------|------|-----------|
| 微信发消息 | 打开微信 → 搜索联系人 → 发送消息 | 80% |
| 保存图片 | 在微信/浏览器中长按保存图片 | 75% |
| 高德导航 | 打开高德 → 搜索目的地 → 发起导航 | 80% |
| WPS打开文件 | 打开WPS → 浏览文件 → 打开文档 | 85% |
| 支付宝账单 | 打开支付宝 → 查看账单 | 80% |

## 4. 技术约束

- Android minSdk: 26
- Android targetSdk: 34
- Rust: stable edition 2021
- Kotlin: 1.9.x
- Jetpack Compose: 1.5.x
